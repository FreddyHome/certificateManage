**技术：** Java 21、Spring Boot 3.5、JdbcTemplate/H2、Vue 3、TypeScript、现有 Element Plus/Vite，不更换运行架构。

## 接口约定

新增 `GET /api/v1/certificates/page` 与 `GET /api/v1/certificates/archived/page`。

- 参数：`owner`（普通列表默认 OWN，归档可空）、`kind`（ROOT/INTERMEDIATE/LEAF，可空）、`query`（CN/客户包含搜索，可空，最长200）、`purpose`（AS2/HTTPS/GENERAL，可空）、`status`（未生效/已过期/即将过期/有效，可空）、`page`（默认1，1～1000000）、`size`（默认20，1～100）。
- 响应：`{items: CertificateRow[], total: number, page: number, size: number}`。
- 返回当前表格所需字段：id/name/owner/enabled/archivedAt/customer/customerId/purpose/kind/depth/issuer/notBefore/notAfter/status/hasKey/serial；不返回 Subject、SAN、指纹等详情字段。
- 稳定排序 `not_after ASC, id ASC`，保留当前页面筛选排序语义；归档与普通范围严格分离。
- 搜索中的 `%`、`_` 为普通字符；状态使用与原展示相同的边界（过期含截止时刻，提醒严格早于阈值时刻）。
- 自有三表各自每页20条；客户与归档每页20条；筛选变化重置页码，搜索300ms防抖，旧响应不能覆盖新状态；删除/归档/恢复后空页自动回退。

## Review Focus

1. 并发请求中 mapper 不得再获取第二连接；用固定 SQL 次数和10并发回归验证。
2. 分页筛选不能造成跨归属、归档混入，通配符应按字面搜索。
3. 有效期阈值边界、同到期时间的 ID 排序和末页回退应一致。
4. 敏感 API 继续 no-store，只有带内容哈希资源长期缓存，HTML 不永久缓存。
5. 按需引入仍需覆盖消息、确认框、loading、中文 locale 及所有现有页面。
