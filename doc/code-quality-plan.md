# 开发规范与局部重构计划

日期：2026-11-12。范围：按用户选择，保持现有功能、API、数据库和统一部署方式。

## 方案

采用渐进式职责拆分：网络基础设施保留在 api，界面提示放入 composables，通用纯函数放入 utils，业务请求放入 services。客户模块先补齐类型和服务边界，其他模块逐步迁移。不进行全目录搬迁或引入新依赖。
