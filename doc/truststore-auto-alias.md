# Truststore 自动别名

新建 truststore 条目无需用户填写别名。后端在校验及冻结任务引用时，为每个信任证书生成 `规范化 CN-完整 SHA-256 指纹`，指纹来自证书 DER 材料。CN 转小写，非 ASCII 字母、数字、点、下划线及连字符替换为连字符，去除首尾的点、下划线和连字符，最多保留 100 字符；空名称使用 certificate。别名不超过 180 字符。

包含证书链时，各层使用自身信息生成独立别名。同一证书稳定复用，同名不同证书由完整指纹区分。已有非空别名保留，私钥条目保持现有明确别名规则。前端 truststore 去除别名输入，旧配置只读展示已有别名。

实施与验证：

1. 增加实际证书、工作流解析、JKS/PKCS12 输出的回归测试，先确认空别名用例失败。
2. 修改 WorkflowValidator，为缺省别名的信任条目逐材料生成别名；保留旧别名及材料去重。
3. 更新 StoreStepConfig，取消 truststore 手动别名输入并说明自动生成规则。
4. 执行后端测试、格式检查、前端验证及生产打包，重启并检查首页和 API。
