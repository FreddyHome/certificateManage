# 证书启用状态

日期：2026-11-12。范围：自有与客户证书均可独立启用或禁用；用户确认禁用停止同步、签发和到期通知，保留查看和导出。

- V7 迁移在 certificate_assets 上新增 enabled，默认 true；不改共享 certificate_materials。同一公钥在不同客户或归属下的状态独立，不级联其他资产，不更改证书的有效期状态。
- 两个管理列表新增“启用状态”开关；PATCH /api/v1/certificates/{id}/enabled 接收显式布尔 enabled。操作与审计共同提交，支持重新启用；重导入相同证书不自动清除禁用状态。
- 禁用CA从签发者列表排除，直接请求签发也会被拒绝。签发入库与禁用操作共用同步锁并复验状态。管理详情、链查看、公钥和私钥导出保持原权限规则。
- 同步选项排除禁用资产，校验、证书库制作和实际执行均拒绝业务使用。排队快照引用（包括服务器信任证书）在后续步骤前检查当前启用状态。已有步骤已开始的远端操作无法因本地开关回滚。
- TNPartner 在同客户用途下排除禁用资产，再按有效且到期最晚的规则选取。明确配置了禁用证书的其他任务会校验失败，不会静默丢弃证书条目。
- 通知扫描不生成禁用资产任务，待投递任务保留但不领取，禁用资产不允许手动重试；领取更新再次检查状态。已经开始的SMTP投递不强行中断。重新启用后沿用原有提醒节点、投递幂等和重试规则，不补历史节点。

## 验证

新增证书状态接口、审计、CA禁用、排队任务状态复查与恢复、通知四种暂停/恢复边界回归；真实TN HTTP回归验证禁用最新证书后选择下一有效证书。前端同步选项契约测试加入禁用证书过滤断言。

本轮验证后端50项、前端15项测试，Java/前端格式、类型检查及前端生产构建。新迁移会在下一次运行最新打包版本时生效；本轮未自动提交、上传或重启服务。

静态审查补齐服务器信任证书选择和保存入口：禁用资产不得新增引用；已有禁用选择显示状态且可以移除。
