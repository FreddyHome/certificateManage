# 证书归档

日期：2026-11-12。用户确认：归档可恢复，归档停止业务使用，保留查看和导出。

## 约定

- 自有与客户证书管理提供归档，普通列表不显示归档资产；独立“证书归档”菜单显示两类资产。
- archived_at 与 enabled 分开维护。归档不修改启用状态，恢复清除归档标记并保留原启用状态；归档时不允许从管理接口启用或禁用。
- 归档资产不能用于签发、同步、TNPartner 自动选择、服务器信任新增或到期通知。执行前与通知领取时继续检查归档状态。已经发生的远端副作用和开始发送的邮件不因归档回滚。
- 归档允许保留现有引用；删除仅允许在归档内进行，沿用原逻辑删除、链引用及任务/信任/活跃执行保护，保留审计和历史材料。
- 旧的已删除记录保持删除状态，不自动恢复为归档；显式重新导入已删除证书沿用原恢复语义。重新导入未删除的归档资产不解除归档。
- 新增 V8 迁移；本轮测试通过后重新打包并重启，使用原数据库和主密钥。

## 接口

- POST /api/v1/certificates/{id}/archive
- POST /api/v1/certificates/{id}/restore
- GET /api/v1/certificates/archived?owner=OWN 或 CUSTOMER，可省略 owner 查询全部
- DELETE /api/v1/certificates/{id}：仅归档内允许删除
