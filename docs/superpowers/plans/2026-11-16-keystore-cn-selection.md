# keyStore 同 CN 自动选证

需求：自有证书可能存在多个。IS keyStore 自动模式以所选自有叶子证书的 CN 精确匹配，在每次入队时选择含私钥、启用、未删除/归档、整条链当前有效且叶子到期时间最晚的证书。到期相同按 ID 降序。无可用链时失败，入队后沿用冻结快照。指定模式保留固定引用。沿用现有 selectionMode 和 certificateId，不增加迁移。

方案：复用业务组件 prepare 的入队校验和引用解析，在固定证书选择处增加候选查询。相比执行过程中替换材料，这样可以保持证书、私钥和审计快照一致。前端显示自动/指定模式和自动解析链；CN 相同跨用途匹配，遵循本次用户指定的 CN 规则。
